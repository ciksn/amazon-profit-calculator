# 竞品统计国家卡片复制设计

## 目标

在“竞品数据统计”区域中，点击任一有数据的国家卡片，将该站点的前三平均销售额和前三平均利润率复制到剪贴板。服务器部署版与 GitHub Pages 版保持一致。

## 交互设计

- 整张国家卡片作为复制入口，鼠标悬停和键盘聚焦时显示可操作状态。
- 卡片支持鼠标点击，以及聚焦后按 Enter 或空格复制。
- 卡片提供明确的无障碍名称，说明将复制该站点竞品统计。
- 复制成功后沿用页面现有提示组件，显示对应站点已复制。
- 页面顶部现有“复制统计”按钮及其批量复制行为保持不变。

## 复制格式

复制单行纯文本，格式为：

```text
前三平均销售额USD/前三平均利润率%
```

例如：

```text
1,085,439USD/64.8%
```

销售额使用千分位且不保留小数；利润率沿用当前展示精度，保留一位小数。

## 实现范围

- 在竞品统计卡片渲染结果中保存国家代码，并加入按钮语义所需的键盘属性。
- 复用当前的剪贴板写入能力，新增单站点统计复制逻辑。
- 在统计卡片容器上使用事件委托，避免每次重新渲染后单独绑定事件。
- 为可点击、悬停、聚焦和复制反馈状态补充样式。
- 修改 `public` 源文件后运行 GitHub Pages 构建，将相同产物同步至 `docs`。

## 异常处理

- 只为已经生成统计结果的卡片提供复制入口，因此正常情况下不存在空数据复制。
- 剪贴板写入失败时沿用现有错误提示路径，不静默失败。
- 点击卡片内未来可能出现的交互控件时，不应重复触发卡片复制。

## 测试与验收

- 自动测试先验证复制文本格式、卡片交互属性、事件绑定和样式钩子。
- 确认美国站示例复制为 `1,085,439USD/64.8%`。
- 确认销售额四舍五入为整数、带千分位，利润率保留一位小数。
- 确认鼠标点击、Enter 和空格均可触发复制。
- 运行完整测试、GitHub Pages 构建，并确认 `public` 与 `docs` 对应资源一致。
