# 飞书卡片版品类搜索选择设计

## 目标

将飞书卡片版顶部的原生品类下拉框改为可搜索的选择框，帮助用户在品类较多时快速定位并切换已有品类。

## 范围

- 仅改动顶部品类选择控件及其交互。
- 保留现有“新建”和“删除”按钮、位置与业务行为。
- 搜索只匹配已有品类，不提供通过搜索词新建品类的入口。
- 同步维护 `public` 正式页面和 `docs` 静态发布版本。

## 交互设计

1. 输入框默认显示当前品类名称。
2. 点击或聚焦输入框时，结果面板展示全部已有品类。
3. 输入关键词时，按品类名称进行不区分大小写的包含匹配，并实时刷新结果。
4. 用户点击结果，或使用上、下方向键定位后按回车，才切换当前品类。
5. 按 Esc 关闭结果面板；焦点离开控件且未选择结果时，输入框恢复当前品类名称。
6. 没有匹配结果时，面板显示“未找到品类”，不创建数据。
7. 当前品类在结果中有明确的选中状态，键盘定位项有独立高亮状态。

## 数据流与兼容性

- 继续使用启动数据中的 `projects` 作为品类列表，不新增接口。
- 选择结果后复用现有项目切换流程：读取项目、更新地址中的 `project` 参数、刷新产品参数、利润结果和竞品数据。
- 新建或删除品类后，沿用现有刷新逻辑重新生成搜索候选项并更新当前名称。
- 控件使用组合框语义和列表框语义，维护展开状态、当前定位项与选中项，支持鼠标和键盘操作。

## 异常与边界情况

- 品类名称按纯文本输出，避免将名称作为 HTML 解析。
- 品类列表为空时显示“未找到品类”；现有初始化逻辑仍会保证页面拥有可用项目。
- 快速重复选择时，以最后一次完成的切换为当前状态；加载失败沿用页面现有错误提示机制。
- 在窄屏下，搜索选择框继续占据顶部操作区的整行宽度。

## 验证

- 验证聚焦展示、关键词过滤、无结果提示和失焦恢复。
- 验证鼠标选择以及方向键、回车、Esc 操作。
- 验证切换后地址、产品数据、利润结果和竞品数据对应所选品类。
- 验证新建、删除流程不受影响，候选列表能随之更新。
- 验证正式页面与静态发布版本保持一致。
